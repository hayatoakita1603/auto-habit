# ホーム画面仕様

## 概要

習慣登録済みユーザーが最初に見る画面。今日の達成記録とストリーク確認ができる。

## 表示要素

| 要素 | 内容 |
|---|---|
| 習慣名 | 登録した習慣のタイトル |
| 連続達成日数 | 今日または直近の連続達成日数（ストリーク） |
| 達成ボタン | 今日未達成の場合に表示。タップで達成記録 |
| 達成済みテキスト | 今日達成済みの場合に表示 |

## データ構造

### Firestoreパス

```
users/{userId}/achievements/{YYYY-MM-DD}
  completedAt: Timestamp
```

日付文字列（YYYY-MM-DD）をドキュメントIDとすることで、1日1回の重複防止と日付指定取得を実現。

## ストリーク計算ルール

- 今日達成済み: 今日から遡って連続している日数をカウント
- 今日未達成: 昨日から遡ってカウント（当日達成前でもストリークが途切れない）
- 達成なし: 0

## フック

- `useHabit(user)` — 習慣名を含む `Habit` オブジェクトを提供
- `useAchievement(user)` — `todayDone`, `streak`, `markDone` を提供

## 画面遷移

`App.tsx` にて `hasHabit === true` のときに `HomeScreen` を表示。
